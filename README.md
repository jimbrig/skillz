> [!NOTE]
> *This is my collection of agentic coding related skills I have curated and collected or created over time.*

## Skills Collection

### General Skills

- [everything-search](skills/everything-search/): A skill that uses [Everything](https://www.voidtools.com/) to search across the machine's file system.

### R Skills

- [r-arf](skills/r-arf/): A skill for usage guidance for the [`arf`](https://github.com/eitsupi/arf) CLI tool and R console.

- [r-cli](skills/r-cli/): A skill for how to properly use the [`{cli}`](https://cli.r-lib.org/) package for semantic command line interfaces in R and nice console output.

- [r-httr2](skills/r-httr2/): A skill for how to properly use the [`{httr2}`](https://httr2.r-lib.org/) package for robust API client library development.

- [r-mapgl](skills/r-mapgl/): A skill for how to properly use the [`{mapgl}`](https://mapgl.r-lib.org/) package for mapping with [maplibre](https://maplibre.org/) in R.

- [r-plumber2](skills/r-plumber2/): A skill providing guidance on how to use the new [`{plumber2}`](https://plumber2.r-lib.org/) package for building APIs in R.

- [r-s3](skills/r-s3/): A skill providing guidance related to the `S3` OO system in R.

- [r-s7](skills/r-s7/): A skill providing guidance related to the [`{s7}`](https://s7.r-lib.org/) package for a modern OO system in R.
